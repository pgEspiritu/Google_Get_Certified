## 1. Google AI Studio vs. Agent Studio

**Question:** What is the primary distinction between Google AI Studio and Agent Studio in terms of their target users?

- A. Google AI Studio is for accessing image generation models, while Agent Studio is for text-based models.
- **B. Google AI Studio is designed for beginners and experimentation, while Agent Studio caters to professionals and larger-scale projects.** ✅
- C. Google AI Studio is for building custom models, while Agent Studio is for using pre-trained models.
- D. Google AI Studio requires coding experience, while Agent Studio offers a no-code interface for interacting with models.

**Explanation:**
- **Google AI Studio:** Prioritizes accessibility, ease of use, experimentation, and prototyping.
- **Agent Studio:** Provides advanced features, scalability, and capabilities for professional and enterprise projects.

## 2. Multi-Agent Systems

**Question:** Which scenario best illustrates the concept of a multi-agent system in generative AI?

- A. A single AI agent capable of performing multiple tasks, such as writing emails and summarizing documents.
- **B. A system where multiple specialized AI agents collaborate to achieve a complex goal, such as booking a trip.** ✅
- C. An AI agent that can be customized with different parameters to adapt to different tasks.
- D. An AI agent that uses multiple tools, like a database and a web search API, to complete a task.

**Explanation:**
- A multi-agent system involves multiple specialized agents collaborating to accomplish a larger objective.
- Example: A travel application uses separate flight, hotel, and attractions agents.

## 3. Agent Tools for Scheduling

**Question:** An AI agent needs to access team calendars, propose suitable time slots, and send invitations. Which combination of agent tools is most essential?

- **A. Extensions and plugins.** ✅
- B. Plugins and data stores.
- C. Data stores and functions.
- D. Functions and databases.

**Explanation:**
- **Extensions:** Connect the agent to external APIs, such as Google Calendar, to access calendar information.
- **Plugins:** Provide specialized functionalities, such as scheduling meetings and sending invitations.

## 4. Temperature Parameter

**Question:** Which parameter in Google AI Studio controls the randomness and creativity of Gemini's output?

- A. Output length
- **B. Temperature** ✅
- C. Token count
- D. Safety settings

**Explanation:**
- **Low temperature:** More focused, predictable, and consistent responses.
- **High temperature:** More varied, creative, and unpredictable responses.

## 5. Reasoning Loop

**Question:** Which statement best describes the function of a reasoning loop within a generative AI agent?

- A. It establishes a one-time set of instructions for the agent to follow without deviation.
- B. It restricts the agent's actions to a predefined set of responses, ensuring predictable behavior.
- **C. It guides the agent through an iterative process of observation, internal reasoning, and decision-making to solve tasks.** ✅
- D. It enables the agent to interact with users conversationally, responding to prompts and questions.

**Explanation:**
- A reasoning loop drives an agent's problem-solving process.
- It repeatedly:
  1. Observes information or tool outputs.
  2. Reasons about the current situation.
  3. Decides on the next action.
  4. Evaluates the result and continues until the task is completed.
