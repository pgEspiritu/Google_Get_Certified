
# 🌐 Google's Generative AI APIs

## 📖 Introduction

Google provides generative AI APIs that allow developers to access pre-trained Large Language Models (LLMs) and customize them for specific tasks.

### 🚀 Capabilities of Google's Generative AI APIs

- ✍️ Text completion and generation.
- 💬 Multi-turn conversations and chat.
- 💻 Code generation.
- 🖼️ Image generation and customization.
  - Example: **Nano Banana API** for generating and customizing images.

### 🛠️ Tools for Experimenting with Generative AI APIs

Google provides two main tools for accessing and experimenting with Gemini models:

1. **Google AI Studio**
2. **Agent Studio** – Part of the Gemini Enterprise Agent Platform (Agent Platform).

## 1. 🧪 Google AI Studio

- A web-based tool for exploring Gemini models and building applications using the Gemini Developer API.
- Designed for:
  - Developers.
  - Students.
  - Researchers.
  - Beginners and non-technical users.

### Key Features

- Experiment with Gemini models.
- Test prompts and different creative text formats.
- Adjust sampling parameters and model settings.
- Add system instructions to define an agent's overall tone, style, and behavior.
- Configure safety settings.
- Add tools, such as:
  - Function calling.
  - Structured output.
  - Google Search grounding.
- Prototype AI-powered applications using natural language prompts.
- Generate application code that can be used in your own projects.

### Access and Limitations

- Accessible through a standard Google account.
- Has usage limits, including:
  - Queries per minute.
  - Requests per minute.
  - Tokens per minute.
- Primarily intended for learning, experimentation, prototyping, and small-scale projects.
- Requires an API key before using generated code in your own application.

## 2. ☁️ Agent Studio

- A Google Cloud console tool for prototyping and testing generative AI models.
- Part of the **Gemini Enterprise Agent Platform (Agent Platform)**.
- Designed for professional developers, researchers, and enterprise use cases.

### Key Features

- Test models using prompt samples.
- Design and save prompts.
- Tune foundation models.
- Prototype and develop generative AI solutions.
- Offers enterprise-grade security and compliance features.
- Provides more flexible usage quotas, which may be increased upon request.

### Access and Limitations

- Accessed through Google Cloud.
- Usage is subject to service charges.
- Better suited for professional and larger-scale applications.

## ⚖️ Google AI Studio vs. Agent Studio

| Attribute | Google AI Studio | Agent Studio |
|---|---|---|
| **Focus** | Easy-to-use environment for exploring Gemini, testing prompts, and experimenting with parameters | More comprehensive environment for professional model prototyping, tuning, and development |
| **Target Users** | Beginners, hobbyists, students, and developers starting with Gemini | Professionals, researchers, and developers |
| **Access** | Standard Google account | Google Cloud |
| **Usage Limits / Cost** | Usage limits based on queries, requests, and tokens per minute | Usage-based service charges and more flexible quotas |
| **Advantages** | Simple interface, accessible, and easy to learn | Enterprise-grade security, compliance, and scalability |
| **Best For** | Learning, experimentation, and small-scale prototypes | Professional and enterprise-level applications |

### 💡 Which Tool Should You Choose?

- **Choose Google AI Studio if:**
  - You are new to generative AI.
  - You want to experiment with Gemini models.
  - You need to test prompts and sampling parameters.
  - You want to build small-scale prototypes.

- **Choose Agent Studio if:**
  - You are developing professional AI solutions.
  - You need more flexible usage quotas.
  - You require enterprise-grade security and compliance.
  - You are working toward larger-scale applications.

## 🎥 Google AI Studio Demonstration

### Main Interface and Capabilities

Google AI Studio provides an environment for prototyping applications using the Gemini API.

#### 1. Explore Gemini Models and Build Apps

- Explore available Gemini models.
- Start prompting using a familiar chat-style interface.
- Use the vibe coding feature to create applications through natural language descriptions.

#### 2. System Instructions

- Configure system instructions to establish the agent's:
  - Overall tone.
  - Communication style.
  - Behavior.
  - Role and instructions.

#### 3. Tools, Settings, and Parameters

The right-side panel provides options for configuring the selected model or agent.

| Setting / Feature | Purpose |
|---|---|
| Model Selection | Choose the generative AI model or agent |
| Temperature | Control response creativity and randomness |
| Thinking Level | Adjust the model's reasoning effort, where supported |
| Top-p | Control the range of probable tokens considered |
| Safety Settings | Configure content filtering |
| Function Calling | Allow the model to invoke functions |
| Structured Output | Specify the format of generated responses |
| Google Search Grounding | Connect model responses to information from Google Search |

- Available settings vary depending on the selected model or agent.

#### 4. Test Prompts

- Modify parameters and settings.
- Enter different prompts.
- Observe how changes affect the model's responses.
- Compare outputs to identify the most suitable configuration.

#### 5. Vibe Coding and Application Development

- Describe the application you want to build using natural language.
- Gemini generates application code based on your instructions.
- Review and refine the generated application.
- Obtain the generated code for use in your own application.
- Create an API key before using the code.

**Important considerations:**
- Generated code is intended primarily for small-scale projects and prototypes.
- For larger enterprise applications, consider Agent Studio for additional capabilities and enterprise-level requirements.

## 🔑 Key Takeaways

- Google offers generative AI APIs powered by pre-trained models, including Gemini.
- These APIs support text generation, multi-turn chat, code generation, and image generation.
- **Google AI Studio** is ideal for beginners, experimentation, prompt testing, and small-scale prototyping.
- **Agent Studio** is designed for professional development and enterprise-level use cases.
- Google AI Studio allows users to configure system instructions, sampling parameters, safety settings, function calling, structured output, and Google Search grounding.
- Vibe coding allows users to build AI-powered applications by describing what they want in natural language.
- Generated application code requires an API key before integration into your own application.
