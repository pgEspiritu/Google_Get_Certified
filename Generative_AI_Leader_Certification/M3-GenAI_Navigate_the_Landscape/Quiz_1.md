## 1. What are the two key elements that distinguish AI agents from standalone AI models?

**Correct Answer: B. Reasoning loop and tools.**

**Explanation:**

AI agents have two defining elements:

- **Reasoning loop:** Allows an agent to observe its environment, interpret information, plan, make decisions, and take actions.
- **Tools:** Allow an agent to interact with external systems, databases, APIs, applications, or devices to accomplish tasks.

A standalone AI model primarily processes inputs and generates outputs, while an agent can use tools and perform multi-step actions toward a goal.

## 2. How would the "agents" layer and the "applications" layer work together to create an AI-powered travel planning experience?

**Correct Answer: A. The agents layer would define the AI's capabilities (searching, booking, recommending), while the applications layer would provide the user-facing tool (website or app) to interact with the agent.**

**Explanation:**

The two layers serve different but complementary purposes:

- **Agents layer:** Defines the tasks and actions the AI can perform, such as searching for flights, recommending destinations, comparing hotels, and assisting with bookings.
- **Applications layer:** Provides the user interface through which customers interact with the AI agent, such as a website or mobile application.

**Key takeaway:** The agent determines what the AI can do, while the application provides how users interact with it.

## 3. How would the "agents" layer contribute to the functionality of a personalized news reader application?

**Correct Answer: C. The agents layer would define the specific tasks the AI performs, such as filtering articles, summarizing information, and making recommendations.**

**Explanation:**

The agents layer determines the actions and goals of the AI within the application.

For a personalized news reader, an AI agent could:

- Filter articles based on user interests.
- Summarize lengthy news reports.
- Recommend relevant articles.
- Organize news by topic or category.
- Adjust recommendations based on user preferences and interactions.

The application layer provides the interface, while the agents layer handles the AI-driven tasks.

## 4. Which layer of the generative AI landscape would be MOST crucial in defining the behaviors and capabilities of AI-powered NPCs?

**Correct Answer: D. Agents.**

**Explanation:**

AI-powered non-player characters (NPCs) need to perform specific actions and respond to events within a game environment.

The agents layer defines these behaviors and capabilities, including:

- Engaging in conversations with players.
- Reacting to player actions and environmental events.
- Making decisions based on game situations.
- Adapting their behavior according to context.
- Performing specific tasks within the game.

**Key takeaway:** Models provide the underlying AI capabilities, but agents determine how those capabilities are used to perform actions and achieve goals.

## 5. Which layer of the generative AI landscape would provide the necessary computational power and storage for training a generative AI model?

**Correct Answer: D. Infrastructure.**

**Explanation:**

The infrastructure layer provides the hardware and software foundation needed to develop, train, deploy, and operate AI models.

It includes:

- **GPUs and TPUs:** Specialized processors for computationally intensive AI workloads.
- **Storage:** Systems for storing and accessing large datasets and model files.
- **Networking:** High-speed connections that enable efficient communication between computing resources.
- **Computing resources:** Servers, cloud infrastructure, and other processing capabilities.

**Key takeaway:** Infrastructure supplies the computational resources that support all the other layers of the generative AI landscape.
