# Agents and Generative AI-Powered Applications

## 1. What Can Agents Do?

Generative AI agents can process information, reason through complex tasks, and take actions using available tools and resources.

They can be applied in different areas, including:
- **Customer service:** Answer inquiries, troubleshoot problems, and assist customers.
- **Employee productivity:** Automate repetitive tasks, retrieve information, and assist with daily workflows.
- **Creative tasks:** Generate ideas, develop content, and support creative processes.
- **Research and analysis:** Gather information, analyze documents, and prepare summaries.

### What Is a Generative AI Agent?

A **generative AI agent** is an application or software system that attempts to achieve a goal by observing its environment and taking actions using the tools available to it.

In simpler terms, an AI agent does more than generate a response. It can determine what needs to be done, use available tools, and perform a sequence of actions to accomplish a specific objective.

For example, when asked to prepare a research summary, an AI agent might:
1. Understand the research request.
2. Search for relevant documents.
3. Retrieve and examine information.
4. Organize the findings.
5. Generate a summary based on the collected information.

### Pre-built Agents vs. Custom Agents

Organizations can use generative AI through pre-built solutions or develop agents tailored to their requirements.

| Type | Description | Example |
|---|---|---|
| Pre-built agents | Ready-made agents or applications designed for common tasks. | A customer service chatbot that answers frequently asked questions. |
| Custom agents | Agents developed or configured to address specific organizational needs and workflows. | A government research assistant that searches internal statistical publications and reports. |

Google Cloud tools, such as AI Applications and its agent development capabilities, can help teams create AI-powered experiences using natural language and visual tools, reducing the need to write complex code for every task.

## 2. How Do Agents Relate to Generative AI-Powered Applications?

Think of agents as the intelligent components within a larger generative AI-powered application.

An application provides the user interface and overall environment, while agents perform specific tasks using AI models, tools, and available information.

Agents bring three important capabilities to applications:

### A. Understanding and Responding to Natural Language

Agents allow applications to understand user requests expressed in everyday language.

This makes applications more intuitive because users do not always need to follow rigid commands or navigate complicated menus.

**Example:**

Instead of manually searching through a government website, a user can ask:

"Where can I find the latest regional poverty statistics?"

An AI-powered application can use an agent to interpret the question, search relevant sources, and provide an appropriate response.

### B. Automating Complex Tasks

Agents can handle multi-step processes by gathering information, making decisions, and taking actions.

They can use different tools and systems to complete tasks that would otherwise require several manual steps.

**Example:**

An employee asks an agent to prepare a summary of several research documents.

The agent can:
1. Locate the relevant documents.
2. Extract important information.
3. Compare findings.
4. Organize the information.
5. Generate a consolidated summary.

**Key idea:** Agents can coordinate multiple actions instead of simply responding to a single question.

### C. Personalization

Agents can use available user preferences, interaction history, and contextual information to tailor their responses and services.

**Example:**

A personalized learning application can identify topics where a student needs improvement and recommend appropriate lessons and exercises.

**Important distinction:** Personalization does not necessarily mean that an AI model is retrained for every user. It can also use saved preferences, contextual information, and user-specific data.

## 3. What Is the Role of Agents in Generative AI-Powered Applications?

Generative AI-powered applications are the user-facing layer of an AI solution. They provide the structure and context within which agents operate.

Applications define:
- The user interface.
- The overall purpose and goals.
- The tasks users can perform.
- The systems and services that agents can access.
- How users receive and interact with the results.

An application can contain multiple agents, each specializing in a particular task.

When several agents collaborate within one application, this is called a **multi-agent system**.

### What Is a Multi-Agent System?

A multi-agent system consists of multiple specialized agents that work together to accomplish a broader objective.

Instead of assigning every task to one agent, responsibilities can be distributed among agents with different capabilities.

**Example: Travel Booking Application**

A travel booking application may use multiple agents:

| Agent | Responsibility |
|---|---|
| Flight booking agent | Searches for flights based on the user's preferences. |
| Hotel booking agent | Finds suitable hotels based on budget and location. |
| Travel recommendation agent | Suggests activities, attractions, and destinations. |
| Itinerary planning agent | Organizes selected flights, hotels, and activities into a travel plan. |

The application provides the interface where users can review recommendations, select options, and make reservations.

### Other Examples of Multi-Agent Applications

**A. Customer Support Application**

Different agents can perform specialized customer service tasks.

| Agent | Responsibility |
|---|---|
| Inquiry agent | Answers common questions and provides information. |
| Troubleshooting agent | Helps diagnose and resolve technical problems. |
| Escalation agent | Identifies complex issues that require human assistance and routes them appropriately. |

The application provides the chat interface and connects agents to customer support systems.

**B. Personalized Learning Application**

An educational application can use specialized agents to support students.

| Agent | Responsibility |
|---|---|
| Assessment agent | Evaluates a student's existing knowledge. |
| Recommendation agent | Suggests appropriate learning materials. |
| Exercise generation agent | Creates personalized quizzes and practice exercises. |
| Progress monitoring agent | Tracks learning progress and identifies areas for improvement. |

The application provides the learning environment, displays lessons and exercises, and tracks student progress.

## 4. Comparing Agents and Generative AI-Powered Applications

| Aspect | AI Agent | Generative AI-Powered Application |
|---|---|---|
| Primary role | Performs specific tasks and actions. | Provides the environment and interface for users. |
| Main focus | Reasoning, decision-making, and task execution. | User interaction and delivery of AI capabilities. |
| Capabilities | Uses models, tools, and information to accomplish goals. | Integrates agents, models, and other services. |
| Example | An agent that searches flights and compares prices. | A travel booking application where users search and book trips. |

**Remember:**
- An **agent** performs tasks and takes actions.
- An **application** provides the interface and environment through which users access those capabilities.
- A **multi-agent system** allows several specialized agents to collaborate within a larger application.

## 5. Key Takeaways

- Generative AI agents can process information, reason through tasks, and take actions using available tools.
- Agents can be pre-built or customized for specific organizational requirements.
- Agents enhance applications through natural language understanding, task automation, and personalization.
- Generative AI-powered applications provide the user-facing interface and define the context in which agents operate.
- Multiple specialized agents can work together in a single application. This is known as a multi-agent system.
- Agents can support applications in customer service, travel booking, education, research, and employee productivity.
