# ✍️ Prompting Models

## 🧠 How Are Foundation Models Used for Generative AI?

- **Foundation models** are trained on vast amounts of data, allowing them to learn patterns, relationships, and information from different types of content.
- To use the knowledge and capabilities of these models, users provide **inputs called prompts**.
- A foundation model processes the prompt and generates an appropriate **output**.

### 🔄 Basic Prompting Process

1. **Input (Prompt)** – The user provides an instruction, question, request, or other information.
2. **Model Processing** – The foundation model interprets the prompt based on its training and capabilities.
3. **Output (Response)** – The model generates a response based on the provided prompt.

> 💡 **Key Concept:** A prompt is the input or instruction given to an AI model to guide the output it generates.

## 🌐 Why Are Foundation Models More Flexible?

- Traditional AI models often have specific input requirements.
  - Some models may only process numerical data.
  - Others may be designed specifically to classify emails or recognize images.
- **Foundation models**, especially **multimodal foundation models**, can accept a much broader range of inputs.
  - Text
  - Images
  - Audio
  - Video
  - Code
  - Documents and other supported data formats

- This flexibility allows foundation models to perform different tasks using the same underlying model, depending on the prompt and its capabilities.

## 📥 Prompting Inputs and Outputs

A prompt can take different forms depending on what you want the AI model to accomplish.

| 📥 Input (Prompt) | 📤 Expected Output |
|---|---|
| ❓ A question | An answer to the question |
| 🎨 A text description requesting an image | A generated image |
| 📄 A request to summarize a file | A summary of the file |
| 💻 Sample code containing errors | Corrected code |
| 🌐 A request to translate text | Translated text |
| ✍️ A request to create content | Generated text or creative content |

### Examples of Prompting

- **Question Answering**
  - Prompt: "What is generative AI?"
  - Output: An explanation of generative AI.

- **Image Generation**
  - Prompt: "Generate an image of a modern smart city with sustainable buildings."
  - Output: An AI-generated image based on the description.

- **Document Summarization**
  - Prompt: "Summarize this PDF and identify its five most important findings."
  - Output: A concise summary of the document.

- **Code Correction**
  - Prompt: "Review this Python code, identify the errors, and provide a corrected version."
  - Output: Corrected code with explanations of the changes.

## 🛠️ Prompting, Prompt Engineering, and Prompt Design

- **Prompting** is the process of providing inputs or instructions to a generative AI model to obtain a desired output.
- **Prompt Engineering** involves developing and refining prompts to improve the relevance, accuracy, and usefulness of AI-generated responses.
- **Prompt Design** focuses on structuring prompts clearly and effectively to guide the model toward the intended result.

### 🎯 Why Is Prompting Important?

- Helps communicate what you want the AI model to accomplish.
- Improves the relevance and usefulness of generated outputs.
- Reduces ambiguity and misunderstandings.
- Allows users to take advantage of the model's different capabilities.
- Helps maximize the value of generative AI tools.

## 🔑 Key Takeaways

- Foundation models can be accessed and used through prompts.
- A **prompt is the input** provided to an AI model, while the **output is the response** generated by the model.
- Foundation models are more flexible than many traditional task-specific AI models because they can handle different types of inputs.
- Multimodal foundation models can process multiple types of information, such as text, images, audio, and video.
- Prompting is an important skill for maximizing the capabilities of generative AI.
- Effective prompts can help models generate text, translate languages, create images, write creative content, summarize documents, correct code, and answer questions.
