# Using Generative AI

## 1. What is Generative AI?

Generative AI (Gen AI) is a type of artificial intelligence that can create new content and ideas, including text, images, music, videos, audio, and computer code.

Generative AI can also analyze information, summarize documents, discover insights, and automate tasks that previously required human intervention.

## 2. Four Primary Ways to Use Generative AI

### 2.1 Create

**Concept:** Generate new content using AI based on user instructions or prompts.

**Common Applications:**

- **Writing Content**
  - Generate articles, emails, reports, and social media posts.
  - Create customer service responses using [Conversational AI](https://cloud.google.com/conversational-ai).
  - Draft professional emails using [Gemini in Gmail](https://support.google.com/mail/answer/13955415).

- **Creating Multimedia Content**
  - Generate images for presentations using [Gemini in Google Slides](https://support.google.com/docs/answer/14355071).
  - Create marketing designs and website concepts using [Nano Banana](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-1-flash-image).
  - Produce video tutorials using [Google Vids](https://workspace.google.com/products/vids/).
  - Generate audio and other multimedia content.

- **Generating Computer Code**
  - Generate code in different programming languages.
  - Create unit tests and test cases to reduce manual testing.
  - Generate initial code for software development using [Gemini Code Assist](https://cloud.google.com/products/gemini/code-assist).

**Key Takeaway:** Generative AI helps users produce new content, creative materials, and computer code more efficiently.

### 2.2 Summarize

**Concept:** Condense large amounts of information into shorter, clearer, and more understandable summaries while retaining the most important details.

**Common Applications:**

- **Summarizing Documents and Articles**
  - Summarize lengthy financial reports without reading the entire document.
  - Analyze customer reviews to identify product feedback and customer sentiment.
  - Use tools such as [Gemini Notebook Enterprise](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview) and [Gemini in Looker](https://cloud.google.com/gemini/docs/looker/overview).

- **Extracting Key Takeaways from Meetings and Presentations**
  - Automatically generate meeting notes.
  - Identify important decisions, discussion points, and action items using [Gemini in Google Meet](https://support.google.com/meet/answer/14754931).
  - Summarize client meetings and determine appropriate next steps.

- **Creating Reports from Complex Data**
  - Transform complex datasets into understandable visualizations, such as graphs and charts.
  - Use [Gemini in BigQuery](https://cloud.google.com/gemini/docs/bigquery/overview) to assist with data analysis and reporting.

**Key Takeaway:** Generative AI reduces the time needed to understand large documents, meetings, and complex datasets by extracting relevant information.

### 2.3 Discover

**Concept:** Help users find relevant information, uncover hidden patterns, and obtain useful insights at the right time.

**Common Applications:**

- **Uncovering Hidden Patterns and Insights in Data**
  - Analyze purchasing history and website traffic to forecast future demand and optimize inventory.
  - Identify customer preferences and viewing patterns to provide personalized recommendations.
  - Analyze molecular structures to identify potential drug candidates.
  - Use forecasting and fine-tuning models to support advanced data analysis.

- **Searching for Resources and Documents**
  - Search for specific files and ask questions about document contents using [Gemini in Google Drive](https://support.google.com/drive/answer/14356148).
  - Use AI-powered enterprise search to retrieve organizational knowledge across different data sources.
  - Use [Gemini Enterprise](https://cloud.google.com/gemini-enterprise) to help employees access relevant organizational information.

- **Monitoring Real-Time Events**
  - Detect unusual patterns and anomalies in financial transactions.
  - Identify potentially fraudulent activities and prevent financial losses.
  - Monitor operational activities and identify potential problems.

**Key Takeaway:** Generative AI helps users find information, identify patterns, discover insights, and make more informed decisions.

### 2.4 Automate

**Concept:** Automate repetitive or time-consuming tasks that previously required human intervention.

**Common Applications:**

- **Automated Format Conversion**
  - Convert content into accessible formats in real time.
  - Convert speech into text using Speech-to-Text.
  - Convert text into speech using Text-to-Speech.
  - Translate content into different languages using Translation APIs.

- **Automated Documentation and Information Extraction**
  - Analyze source code and automatically generate technical documentation.
  - Automate contract review and extract important information using [Document AI](https://cloud.google.com/document-ai).
  - Reduce manual documentation and information-processing tasks.

- **Automated Notifications and Alerts**
  - Analyze customer feedback automatically.
  - Generate support tickets based on customer concerns.
  - Trigger notifications and alarms when specific conditions or events occur.

**Key Takeaway:** Generative AI improves productivity by automating repetitive tasks, reducing manual work, and streamlining business processes.

## 3. Multimodal Generative AI

### 3.1 What is Multimodal Generative AI?

**Concept:** Multimodal Generative AI refers to AI models that can process, understand, and integrate information from different types of data or modalities.

Unlike AI applications that focus on a single data type, multimodal AI can work with multiple input formats individually or simultaneously.

**Common Data Modalities:**

- **Text** - Documents, articles, emails, and written instructions.
- **Images** - Photographs, diagrams, charts, and scanned documents.
- **Video** - Recorded meetings, surveillance footage, and video testimonials.
- **Audio** - Speech recordings, conversations, and sound.
- **PDF Files** - Reports, contracts, research papers, and other documents.
- **Sensor Data** - Temperature, pressure, motion, vibration, and other measurements from connected devices.

### 3.2 Multimodal Generative AI Use Cases

#### A. Text and Image

**Scenario:** A marketing team uses generative AI to create social media content.

- Generate written captions, descriptions, and hashtags.
- Create accompanying images that follow brand guidelines.
- Suggest appropriate posting schedules.

**Application:** Combining text generation and image generation to produce complete marketing materials.

#### B. Text and PDF File

**Scenario:** A legal team uses generative AI to analyze lengthy legal contracts.

- Read and summarize PDF contracts.
- Answer specific questions about contract clauses.
- Identify potential legal risks and implications.
- Suggest alternative wording or contract provisions.

**Application:** Combining document processing and text generation to support legal document analysis.

#### C. Text, Video, and Data

**Scenario:** A market research firm analyzes customer testimonials and survey responses.

- Analyze video testimonials.
- Extract and interpret spoken words from video recordings.
- Integrate customer feedback with survey datasets.
- Identify common themes, customer pain points, and overall satisfaction.

**Application:** Combining video analysis, speech or text processing, and structured data analysis to understand customer sentiment.

#### D. Sensor Data and Video

**Scenario:** A manufacturing company uses generative AI to improve workplace safety.

- Analyze real-time camera feeds.
- Process sensor readings from equipment and the surrounding environment.
- Identify potential hazards, such as spills and equipment malfunctions.
- Generate immediate alerts to warn workers about potential dangers.

**Application:** Combining visual information and real-time sensor data to support workplace monitoring, hazard detection, and safety management.

## 4. Summary of Key Concepts

| Concept | Primary Purpose | Example |
|---|---|---|
| **Create** | Generate new content | Writing reports, creating images, generating code |
| **Summarize** | Condense information | Summarizing reports and meeting notes |
| **Discover** | Find information and insights | Identifying trends, searching documents, detecting anomalies |
| **Automate** | Perform repetitive tasks | Document generation, translation, notifications |
| **Multimodal AI** | Process and combine different data types | Analyzing videos, text, images, and sensor data together |

## 5. Important Learning Points

- Generative AI is not limited to creating text. It can also generate images, videos, audio, and computer code.
- Generative AI can be used for both content creation and information analysis.
- Summarization helps reduce information overload by extracting relevant details.
- Discovery enables organizations to identify patterns, retrieve information, and generate insights from data.
- Automation reduces repetitive manual work and improves operational efficiency.
- Multimodal AI allows models to understand and process multiple data types, providing richer context for analysis.
- Combining different modalities can improve AI applications, particularly in manufacturing, healthcare, marketing, and research.

## 6. Quick Review

Remember the four primary applications of generative AI:

1. **Create** - Generate new content.
2. **Summarize** - Condense large amounts of information.
3. **Discover** - Find information, patterns, and insights.
4. **Automate** - Perform repetitive tasks with minimal human intervention.

**Multimodal Generative AI** expands these capabilities by allowing AI models to process and integrate different types of information, such as text, images, video, audio, PDFs, and sensor data.
