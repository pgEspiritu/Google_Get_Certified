### 📝 Question #1: What is the definition of generative AI?

**Choices:**

- A. A type of predictive model that estimates a relationship by fitting a line to the observed data.
- B. A type of artificial intelligence that can create new content and ideas, including text, images, music, and code.
- C. A type of machine learning algorithm inspired by the human brain that is made up of interconnected nodes.
- D. A type of artificial intelligence that enables a system to autonomously learn and improve using neural networks and deep learning.

**✅ Correct Answer: B.** A type of artificial intelligence that can create new content and ideas, including text, images, music, and code.

**💡 Explanation:**

Generative AI (Gen AI) is a type of artificial intelligence that can generate new content based on patterns learned from its training data. It can create text, images, audio, video, computer code, and other forms of content.

Unlike traditional AI systems that primarily classify, predict, or analyze existing information, generative AI can produce new outputs based on user prompts and learned patterns.

**📚 Why the other choices are incorrect:**

- **A.** Describes regression, particularly linear regression, which estimates relationships between variables.
- **C.** Describes an artificial neural network, a machine learning architecture inspired by the human brain.
- **D.** Describes AI and machine learning capabilities involving neural networks and deep learning, but it does not specifically define generative AI.

**🔑 Key takeaway:** Generative AI creates new content.

### 📝 Question #2: What is the function of an AI agent in the context of generative AI?

A company wants to use an AI agent to automate some tasks. They want everyone to understand the different functions of an AI agent.

**Choices:**

- A. To provide the computational resources needed to train and run Gen AI models.
- B. To store and manage large datasets used for training and running Gen AI models.
- C. To provide a user-friendly interface for interacting with Gen AI models.
- D. To analyze situations, use multiple tools, and make informed decisions without requiring constant human input.

**✅ Correct Answer: D.** To analyze situations, use multiple tools, and make informed decisions without requiring constant human input.

**💡 Explanation:**

An AI agent is designed to perform tasks autonomously or semi-autonomously. It can analyze a situation, understand a goal, plan steps, use available tools, evaluate results, and take action.

Depending on its design, an AI agent may:

- 🧠 Analyze information and context.
- 🎯 Identify the goal it needs to achieve.
- 📝 Develop a plan or sequence of steps.
- 🛠️ Use tools, APIs, databases, or other applications.
- 🔄 Evaluate results and adjust its actions.
- 🤖 Perform tasks with minimal human intervention.

**📚 Why the other choices are incorrect:**

- **A.** Describes computing infrastructure, such as CPUs, GPUs, memory, and cloud resources.
- **B.** Describes data storage and data management systems.
- **C.** Describes a user interface, which allows people to interact with AI models.

**🔑 Key takeaway:** An AI agent can reason about a task, use tools, and take action toward achieving a goal.

### 📝 Question #3: What is the definition of an AI agent?

- 🧠 A reasoning model

- **C.** Describes a user interface.

### 📝 Question #4: What machine learning should the company use for an AI character that learns through rewards and penalties?

A company is developing an AI character for a video game. The AI character needs to learn how to navigate a complex environment and make decisions to achieve certain objectives within the game.

When the AI takes actions that lead to positive outcomes, such as finding a reward or overcoming an obstacle, it receives a positive score. When it takes actions that lead to negative outcomes, such as hitting a wall or losing progress, it receives a negative score.

Through trial and error, the AI gradually improves its ability to play the game effectively.

**Choices:**

- A. Unsupervised learning
- B. Reinforcement learning
- C. Supervised learning
- D. Deep learning

**✅ Correct Answer: B. Reinforcement learning**

**💡 Explanation:**

Reinforcement learning (RL) is a machine learning approach in which an agent learns how to make decisions by interacting with an environment.

The agent performs actions and receives feedback in the form of rewards or penalties. Over time, it learns which actions are more likely to produce favorable outcomes.

The basic process is:

1. 🎮 The agent observes the current environment.
2. 🧭 The agent chooses an action.
3. 🌎 The environment responds to the action.
4. 🎁 The agent receives a reward or penalty.
5. 🧠 The agent adjusts its behavior based on the feedback.
6. 🔄 The process repeats until the agent improves its strategy.

**📚 Why the other choices are incorrect:**

- **A. Unsupervised learning** discovers patterns or groupings in unlabeled data without predefined target answers.
- **C. Supervised learning** learns from labeled examples where the expected output is already provided.
- **D. Deep learning** uses multilayer neural networks to learn complex patterns. It can be used within reinforcement learning, but it is not the specific learning approach described in the question.

**🔑 Key takeaway:** Learning through trial and error using rewards and penalties is reinforcement learning.

### 📝 Question #5: What type of machine learning should the research team use to identify anomalies and natural groupings in unlabeled sensor data?

A research team has collected a large dataset of sensor readings from various industrial machines.

The dataset includes measurements such as:

- 🌡️ Temperature
- 💨 Pressure
- 📳 Vibration levels
- ⚡ Electrical current

The readings are recorded at regular intervals but have not been assigned labels or categories.

The team wants to identify potential anomalies, malfunctions, or natural groupings of machine behavior based on the sensor data alone.

**Choices:**

- A. Deep learning
- B. Reinforcement learning
- C. Supervised learning
- D. Unsupervised learning

**✅ Correct Answer: D. Unsupervised learning**

**💡 Explanation:**

Unsupervised learning is a machine learning approach that discovers patterns, relationships, structures, or groupings in data without predefined labels.

Because the sensor readings do not have assigned categories or known outcomes, the model must discover patterns from the data itself.

Common applications include:

- 📊 Clustering similar machine behaviors.
- 🚨 Detecting anomalies or unusual sensor readings.
- 🔍 Identifying patterns in industrial operations.
- 📦 Grouping similar observations based on characteristics.

For example, a model may identify a group of machines with normal temperature, vibration, and pressure readings, while detecting another group with unusual vibration and temperature combinations that may indicate possible mechanical problems.

**📚 Why the other choices are incorrect:**

- **A. Deep learning** is an architecture-based approach that uses multilayer neural networks. It can be used for anomaly detection, but the question focuses on discovering patterns from unlabeled data.
- **B. Reinforcement learning** involves an agent learning through actions, rewards, and penalties.
- **C. Supervised learning** requires labeled training examples to learn a mapping between inputs and known outputs.

**🔑 Key takeaway:** Unlabeled data used to discover hidden patterns or groupings is associated with unsupervised learning.

### 📝 Question #6: Why is Gemini inappropriate as the core decision engine for a deterministic loan approval system?

A highly regulated financial institution wants to use Gemini as the core decision engine for a loan approval system that will deterministically approve or reject loan applications based on a strict set of predefined criteria.

Why is this an inappropriate use case for Gemini?

**Choices:**

- A. Gemini deployment for this scenario would be too expensive and complex.
- B. Gemini is designed for flexible content generation and inference, not rigid rule-based decisions.
- C. Gemini is not equipped to handle structured numerical data for financial assessments.
- D. Gemini cannot integrate with required financial databases.

**✅ Correct Answer: B.** Gemini is designed for flexible content generation and inference, not rigid rule-based decisions.

**💡 Explanation:**

Generative AI models such as Gemini are designed to understand context, interpret information, generate content, summarize, reason, and respond flexibly to different inputs.

However, a loan approval system based on strict regulatory criteria requires predictable, consistent, and deterministic behavior.

For example, a rule-based loan system might apply predefined conditions:

- 💰 Income must meet a minimum threshold.
- 📉 Debt-to-income ratio must be below a specified limit.
- 📄 Required documents must be complete.
- 📊 Credit score must meet a predefined requirement.

A deterministic system should produce the same outcome when given the same inputs and rules.

Generative AI may produce variable responses or interpretations, making it unsuitable as the sole authority for rigid decisions where consistency, auditability, and regulatory compliance are essential.

A more appropriate design would use a deterministic rules engine for the final approval or rejection decision, while Gemini could assist with tasks such as document summarization, extracting relevant information, explaining policies, or helping employees review applications.

**📚 Why the other choices are incorrect:**

- **A.** Cost and complexity may be considerations, but they are not the fundamental reason the use case is inappropriate.
- **C.** Gemini can process structured and numerical information, although specialized systems may be more appropriate for precise calculations.
- **D.** Gemini can be integrated with external systems and databases through supported tools and integrations.

**🔑 Key takeaway:** Use deterministic systems for strict, rule-based decisions; use generative AI for flexible reasoning, content generation, and assistance.

### 📝 Question #7: What is an example of unsupervised machine learning?

**Choices:**

- A. Predicting subscription renewal based on past renewal status data.
- B. Training a system to recognize product images using labeled categories.
- C. Analyzing customer purchase patterns to identify natural groupings.
- D. Forecasting sales figures using historical sales and marketing spend.

**✅ Correct Answer: C.** Analyzing customer purchase patterns to identify natural groupings.

**💡 Explanation:**

Unsupervised learning identifies patterns or structures in data without predefined labels.

Analyzing customer purchase patterns can reveal groups of customers who share similar purchasing behaviors, even if the groups were not previously defined.

For example, a business might discover customer clusters such as:

- 🛒 Frequent buyers of low-cost products.
- 💎 Customers who purchase premium items.
- 📦 Customers who purchase in bulk.
- 🗓️ Customers who buy primarily during promotional periods.

This process is commonly known as customer segmentation and is often performed using clustering algorithms such as K-Means.

**📚 Why the other choices are incorrect:**

- **A.** Predicting subscription renewal based on known renewal status is supervised learning, specifically classification.
- **B.** Recognizing images using labeled categories is supervised learning.
- **D.** Forecasting sales using historical data and known target values is supervised learning, commonly regression or time-series forecasting.

**🔑 Key takeaway:** Finding natural groupings without predefined labels is unsupervised learning.

### 📝 Question #8: What type of model limitation is demonstrated when a Gen AI model confidently invents fictional scientific explanations?

A user asks a generative AI model about the scientific accuracy of a popular science fiction movie.

The model confidently states that humans can travel faster than light, referencing specific but entirely fictional theories and providing made-up explanations of how this is achieved according to the movie's "established science."

The model presents the information as factual, without indicating that it originates from a fictional work.

**Choices:**

- A. Bias
- B. Hallucination
- C. Knowledge cutoff
- D. Data dependency

**✅ Correct Answer: B. Hallucination**

**💡 Explanation:**

An AI hallucination occurs when a generative AI model produces information that is false, fabricated, misleading, or unsupported, while presenting it as though it were accurate.

Hallucinations may include:

- 📚 Invented facts or explanations.
- 🔗 Fake references, citations, or sources.
- 🧪 Incorrect scientific claims.
- 👤 Fabricated names, events, or quotations.
- 🎯 Confident answers that are not grounded in reliable evidence.

In this scenario, the model presents fictional scientific concepts from a movie as real-world scientific facts without clarifying their fictional nature.

**📚 Why the other choices are incorrect:**

- **A. Bias** refers to systematic unfairness, prejudice, or skewed results that may arise from data, model behavior, or design.
- **C. Knowledge cutoff** refers to the limitation of a model's knowledge based on the time or scope of its training data.
- **D. Data dependency** refers to the reliance of AI systems on the quality, relevance, completeness, and characteristics of their data.

**🔑 Key takeaway:** Confidently presenting fabricated or unsupported information as fact is an AI hallucination.

### 📝 Question #9: What does a diffusion model do?

**Choices:**

- A. Generates high-quality content by refining noise into structured data.
- B. Facilitates the storage and management of structured data.
- C. Analyzes data and predicts future trends and patterns.
- D. Optimizes business processes and resource allocation.

**✅ Correct Answer: A.** Generates high-quality content by refining noise into structured data.

**💡 Explanation:**

A diffusion model is a type of generative AI model commonly used to generate images, audio, and other content.

It generally works through two conceptual processes:

1. 🌫️ **Forward diffusion:** Noise is gradually added to training data until the original content becomes increasingly corrupted.
2. 🖼️ **Reverse diffusion:** The model learns to progressively remove noise and reconstruct meaningful content from a noisy starting point.

During generation, the model begins with random noise and iteratively refines it into a coherent output based on learned patterns and, often, a prompt.

For example, an image generation model can start with random visual noise and gradually transform it into an image matching the prompt, such as a sunset over a mountain landscape.

**📚 Why the other choices are incorrect:**

- **B.** Describes database or data management systems.
- **C.** Describes predictive analytics and forecasting.
- **D.** Describes business process optimization.

**🔑 Key takeaway:** Diffusion models generate content by progressively transforming noise into meaningful outputs.

### 📝 Question #10: What is a critical security consideration when collecting training data for a generative AI customer service model?

An organization is collecting data to train a generative AI model for customer service. They want to ensure security throughout the machine learning lifecycle.

What is a critical consideration at this stage?

**Choices:**

- A. Applying the latest software patches to the AI model on a regular basis.
- B. Monitoring the AI model’s performance for unexpected outputs and potential errors.
- C. Establishing ethical guidelines for AI model responses to ensure fairness and avoid harm.
- D. Implementing access controls and protecting sensitive information within the training data.

**✅ Correct Answer: D.** Implementing access controls and protecting sensitive information within the training data.

**💡 Explanation:**

During the data collection and preparation stage of the machine learning lifecycle, organizations must protect the confidentiality, integrity, and privacy of the information being collected and used for training.

Customer service training datasets may contain sensitive information such as:

- 🔐 Personal identifiable information (PII).
- 🏦 Financial information.
- 📧 Email addresses and contact details.
- 🧾 Customer account records.
- 📄 Confidential business or customer information.

Critical security measures include:

- 🔒 Implementing role-based access controls.
- 🧹 Removing or masking sensitive information when appropriate.
- 🛡️ Encrypting data at rest and in transit.
- 📋 Establishing data governance policies.
- ✅ Ensuring authorized access to training datasets.
- ⚖️ Complying with privacy laws and organizational policies.

Protecting the training data helps prevent unauthorized access, exposure of sensitive information, and misuse of customer data.

**📚 Why the other choices are incorrect:**

- **A.** Software patching is important, but it is primarily a maintenance and vulnerability management activity.
- **B.** Monitoring model performance is important during evaluation, deployment, and operation.
- **C.** Ethical guidelines help ensure fairness and responsible AI behavior, but they do not directly address the data security control emphasized in this question.

**🔑 Key takeaway:** During data collection and preparation, prioritize data privacy, access control, and protection of sensitive information.

# 🧩 Machine Learning Cheat Sheet

## 1. Supervised Learning 🏷️

- Uses labeled data.
- Learns from input-output examples.
- Predicts a known target.

**Common tasks:**
- Classification — predicts a category.
- Regression — predicts a numerical value.

**Examples:**
- Predicting loan default.
- Classifying spam emails.
- Forecasting sales.
- Recognizing labeled product images.

---

## 2. Unsupervised Learning 🔎

- Uses unlabeled data.
- Finds hidden patterns, relationships, or groups.
- Does not require predefined target answers.

**Common tasks:**
- Clustering.
- Anomaly detection.
- Pattern discovery.

**Examples:**
- Customer segmentation.
- Identifying unusual machine sensor readings.
- Discovering purchasing behavior patterns.

---

## 3. Reinforcement Learning 🎮

- Learns through interaction with an environment.
- Uses rewards and penalties.
- Improves decision-making through trial and error.

**Examples:**
- Game-playing AI.
- Robot navigation.
- Autonomous decision-making.
- Learning optimal strategies.

---

## 4. Deep Learning 🧠

- Uses multilayer artificial neural networks.
- Learns complex representations and patterns.
- Can work with large and complex datasets.

**Examples:**
- Speech recognition.
- Computer vision.
- Natural language processing.
- Generative AI.

> 💡 Deep learning is not mutually exclusive with supervised, unsupervised, or reinforcement learning. It can be used as the underlying model architecture within these learning approaches.
